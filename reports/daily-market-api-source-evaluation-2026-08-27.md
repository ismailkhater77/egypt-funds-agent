# تقييم مصادر API لخط بيانات السوق اليومي — 27 أغسطس 2026

## نطاق البيانات المطلوب

يشمل الخط اليومي سبع سلاسل مستقلة: USD/EGP، BTC/USD، XAU/USD، XAG/USD، S&P 500، MSCI Emerging Markets، وEGX30. لن تُنشأ أي بيانات تقديرية أو يُستبدل مؤشر بمنتج مختلف — مثل استخدام ETF بديلًا عن مؤشر MSCI EM — دون موافقة صريحة.

## المرشح الموحد الأول: EODHD

توضح وثائق EODHD الرسمية أنها توفر API منظّمًا لبيانات نهاية اليوم التاريخية للأسهم والصناديق والمؤشرات والعملات والأصول الرقمية، مع تجميع يومي أو أسبوعي أو شهري وقيم OHLC وحقل تاريخ للسجل.[1] وتؤكد صفحة البورصة المصرية تغطية EGX كمنصة تداول وبالتوقيت `Africa/Cairo`، لكن قائمة الصفحة المعروضة تخص الأسهم ولا تثبت بمفردها رمز EGX30 أو مستوى تاريخه.[2]

| عنصر تحقق | النتيجة الأولية | القرار المؤقت |
|---|---|---|
| API مباشر | متاح عبر REST مع `api_token` | مناسب تقنيًا |
| بيانات تاريخية يومية | موثقة لتغطيات EOD المدعومة | مناسب مبدئيًا |
| USD/EGP وBTC/USD | تندرج ضمن العملات والأصول الرقمية المعلنة | يتطلب اختبار الرمز الفعلي |
| XAU/USD وXAG/USD | واجهة السلع والمعادن موثقة كميزة منفصلة | يتطلب تحقق التغطية والترخيص |
| S&P 500 وMSCI EM وEGX30 | المؤشرات مدرجة ضمن فئات البيانات؛ EGX مدرج كبورصة | لا اختيار قبل تحقق رمز كل مؤشر |
| الوصول والحدود | التوثيق يذكر أن كل طلب يتطلب مفتاح API؛ الخطة المجانية محدودة بتاريخ سنة سابقة و20 طلبًا يوميًا | يلزم مفتاح مستخدم وخطة توافق المتطلبات قبل التنفيذ |

لا يُعتمد EODHD نهائيًا في هذه المرحلة؛ نحتاج تحققًا رمزيًا وآليًا لكل سلسلة، وخاصة EGX30 وMSCI EM، ومقارنة ببديل متخصص للمعادن والمؤشرات.

## المرشح الموحد الثاني: Trading Economics

يوثق Trading Economics API تغطية العملات والسلع والمؤشرات والعملات الرقمية، مع بيانات تاريخية يومية ونقطة نهاية منظمة تقبل رمزًا واحدًا أو مجموعة رموز وتعيد `Symbol` و`Date` وOHLC.[3] [4] تُظهر قائمة العملات رسميًا `USDEGP`، وتؤكد صفحة EGX30 أن السلسلة متاحة يوميًا. لكنها تصف EGX30 المعروض بأنه CFD يتتبع المؤشر، لذلك تُخزن هذه العلاقة صراحة ولا توصف القيمة على أنها إغلاق البورصة المصرية الرسمي.[5] [6]

واجهة البحث في الأسواق مصممة لحل الرمز باسم الأداة قبل الجلب، وتعيد وقت آخر تحديث ووحدة القياس ونوع الأداة.[5] وهذا يسمح للجامع بتثبيت رموز USD/EGP وBTC/USD وXAU/USD وXAG/USD وSPX وEGX30 وMSCI EM من استجابة مزود البيانات نفسها بدل تخمين رموزها. يتطلب الاستعمال مفتاح API وخطة اشتراك؛ لم يعد حساب التجربة العام متاحًا، لذلك لا يمكن اختبار النطاق الفعلي أو استيراد بيانات قبل تزويد مفتاح مرخّص.[3] [4]

| المعيار | Trading Economics | Twelve Data |
|---|---|---|
| واجهة واحدة للعملات والسلع والعملات الرقمية والمؤشرات | موثق | موثق |
| USD/EGP | يظهر `USDEGP` في قائمة الأسواق | واجهة الفوركس موثقة؛ يتطلب اختبار الرمز بحساب |
| BTC/USD وXAU/USD وXAG/USD وSPX | فئاتها موجودة في واجهة الأسواق؛ تثبّت الرموز من البحث | واجهة موحدة؛ صفحة عامة تؤكد XAU/USD |
| EGX30 | صفحة EGX30 متاحة يوميًا، لكنها قيمة CFD متتبعة | الرمز المعلن `CASE30` هو EGX 30 Price Return Index |
| MSCI Emerging Markets | يلزم حل الرمز عبر API بمفتاح مرخّص | لم يظهر في بحث المستندات مؤشر MSCI EM نفسه؛ ظهرت ETFs فقط |
| التشغيل اليومي والتاريخ | واجهة تاريخية يومية وحقول تاريخ ووقت تحديث | `time_series` يومي وتاريخي؛ تاريخ اليوم حسب سوق الأداة |

## مصدر MSCI المتخصص وحدود الترخيص

تؤكد MSCI أن **MSCI EM (Emerging Markets) Index** يحمل الرمز `891800` في عرضها الرسمي، وأنها تحسبه يوميًا؛ إلا أن شروط البيانات العامة تقصر الاستعمال على المعلومات غير التجارية وتحظر النسخ أو إعادة التوزيع دون موافقة خطية مسبقة.[7] [8] لذلك لا يجوز للمنصة أن تعتمد صفحة MSCI العامة أو تكشطها كسلسلة تشغيلية. المسار الصحيح، إذا لم يثبت Trading Economics تغطية السلسلة بترخيص المستخدم، هو **MSCI Index API** المرخّص من MSCI، لا بديل ETF.

## قرار هندسي معلّق على اختيار المستخدم والمفتاح

الخيار الأقرب إلى طلب مصدر موحد هو Trading Economics: يتيح واجهة بحث لاكتشاف الرموز ثم واجهة تاريخية يومية موحدة، ويخزن وقت تحديث المزود. لا يبدأ التنفيذ أو الاستيراد قبل أن يختار المستخدم هذا المسار ويقدم مفتاح API فعالاً يمكن اختباره. البديل هو Twelve Data للستة المؤكدة مبدئيًا مع MSCI Index API مرخّص للمؤشر السابع؛ وهو أكثر تعقيدًا ولا يقلل متطلبات الترخيص.

## قرار المستخدم: مصادر مجانية فقط

رفض المستخدم صراحة أي اشتراك أو ترخيص مدفوع. لذلك أُلغي تنفيذ مسار Twelve Data وMSCI API المدفوعين، ولا يُستخدم Trading Economics كبديل. لا يُستبدل أي مؤشر مطلوب بعقد آجل أو CFD أو ETF؛ تتوقف التغطية بدل ذلك إذا فشل الرمز الأصلي أو لم يعد المصدر المجاني متاحًا.

تدعم وثائق Frankfurter 201 عملة من 84 بنكًا مركزيًا مع سعر تاريخي وسلسلة زمنية، وتعلن صراحة عدم اشتراط مفتاح وعدم وجود حصة شهرية.[9] تدعم وثائق CoinGecko خيارًا مجانيًا لبيانات BTC التاريخية، لكن لم يُختر لأن Yahoo Finance المدمج اجتاز بالفعل فحص `BTC-USD` ضمن نفس المسار الذي يوفر مؤشرات الأسهم المطلوبة.[10] GoldAPI يعلن خطة بلا رسوم وبلا بطاقة، 100 طلب شهريًا، وبيانات XAU/XAG الفورية والتاريخية؛ ويحتاج التحديث اليومي طلبين فقط يوميًا، أي نحو 60 طلبًا في شهر من 30 يومًا.[11]

> حد السلامة: يحتاج الاستيراد التاريخي الواسع للذهب والفضة عدد طلبات أكبر من حصة GoldAPI المجانية. لذلك سيُبنى الاستيراد التاريخي بحد أقصى قابل للضبط، ولن ينفذ افتراضيًا بما يستنزف الحصة أو يفترض وجود اشتراك.

## تشغيل يومي بعد النشر

الجداول الجديدة تحفظ **تاريخ السوق** منفصلًا عن وقت الجلب ووقت المصدر؛ لذلك لا تعيد تسمية إغلاق نيويورك أو EGX بتوقيت القاهرة. معالج الجدولة موجود لكنه غير مفعّل ولا يملك `task_uid` بعد. بعد نشر المستخدم للموقع فقط، ينشأ تشغيل واحد يوميًا عند `21:30 UTC` (`0 30 21 * * *`)؛ وهو وقت لاحق لإغلاق السوق الأمريكي المعتاد ويظل كل مصدر مسؤولًا عن تاريخ ملاحظته الفعلي. لا توجد مؤقتات داخل الخادم ولا تشغيل دوري قبل النشر.
